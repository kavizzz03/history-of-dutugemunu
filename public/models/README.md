# Models

- `xbot.glb` — Mixamo "X Bot" skeleton, from the three.js examples (MIT). Used as the animated body for every human hero.
  If you publish the site, check the Mixamo terms and credit Adobe Mixamo.
- `characters/<id>.glb` — OPTIONAL. Drop a rigged, animated, realistic glTF here (e.g. `dutugemunu.glb`, `elara.glb`) and add its id
  to `characters/manifest.json` (e.g. `["dutugemunu","elara"]`). It replaces the built-in body for that hero.
